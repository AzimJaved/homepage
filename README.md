# Azim Javed

A plain HTML and CSS portfolio. No build step, JavaScript, or external dependencies.

Run `npm run dev` and visit http://localhost:3000, or open `index.html` directly.

Publish `index.html` and `style.css` to any static host. Keep the reference PDFs in `source/` out of the deployment.

Content uses the October 2026 LinkedIn export for employment dates and the supplied CVs for project descriptions.
